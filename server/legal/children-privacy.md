## 一、本规则的适用范围和基本原则

1.1 本规则适用于未满 14 周岁的用户（下称“孩子”）使用晓念时，【运营主体待配置】（下称“我们”）对孩子个人信息的处理。孩子的父母或者其他监护人，下称“监护人”。

1.2 本规则依据《中华人民共和国个人信息保护法》第二十八条、第三十一条，《中华人民共和国未成年人保护法》，《儿童个人信息网络保护规定》，《未成年人网络保护条例》等法律法规制定。按照《个人信息保护法》，不满十四周岁未成年人的个人信息属于敏感个人信息。

1.3 本规则是《晓念隐私政策》的组成部分。本规则没有规定的，适用《晓念隐私政策》；两者不一致的，以本规则为准。

1.4 我们处理孩子的个人信息，遵循正当必要、知情同意、目的明确、安全保障、依法利用的原则，只处理提供本服务所必需的最少信息。

## 二、监护人同意

2.1 **孩子第一次进入晓念时，请由监护人本人阅读本规则、《晓念隐私政策》和《晓念用户协议》，同意的，在“青少年守护”弹窗中点“监护人同意”。在监护人同意之前，我们不会为孩子进行微信登录，也不会收集孩子的任何个人信息。**

2.2 本规则以显著、清晰的方式告知下列事项；监护人不同意的，可以选择游客模式：

1. 收集、存储、使用、转移、披露孩子个人信息的目的、方式和范围（第三章至第六章）；
2. 孩子个人信息存储的地点、期限和到期后的处理方式（第七章）；
3. 孩子个人信息的安全保障措施（第八章）；
4. 拒绝的后果（本章 2.4）；
5. 投诉、举报的渠道和方式（第十三章）；
6. 更正、删除孩子个人信息的途径和方法（第九章）。

2.3 需要监护人作出的同意如下：

1. 同意本规则，让孩子登录并使用晓念；
2. **孩子使用心情记录时，另行单独同意**（见第十章）。

2.4 **拒绝的后果：**

- 监护人不同意本规则的，孩子只能使用游客模式：不登录、不保存内容、不使用 AI 功能。
- 监护人不同意心情记录的，孩子不能使用心情记录，其他功能不受影响。

2.5 我们会保存监护人同意的记录（同意的时间、规则版本和同意的事项），用于证明已经取得同意。我们不收集监护人的姓名和联系方式。

2.6 **我们无法核实操作手机的人是否是监护人本人，请监护人亲自阅读并操作。我们发现在没有取得监护人同意的情况下处理了孩子个人信息的，会停止处理并尽快删除。**

2.7 **再次同意。**本章 2.2 所列的告知事项发生实质性变化，或者我们需要超出监护人同意的目的、范围使用孩子个人信息的，我们会再次征得监护人的同意。重新同意之前，监护人和孩子仍然可以导出数据、撤回同意和注销账号，也可以联系我们删除内容，具体见《晓念隐私政策》10.4。

## 三、我们处理孩子的哪些个人信息

3.1 我们只在监护人同意的范围内，处理下列孩子的个人信息：

| 功能 | 处理的信息 | 目的和方式 |
|---|---|---|
| 账号和登录 | 微信为晓念分配的用户标识（OpenID）、账号编号、登录令牌（服务器只保存其不可逆的摘要）、注册和最近活跃时间 | 识别账号，保存孩子的内容。监护人同意后，通过微信登录接口取得 |
| 可选头像和昵称 | 主动选定的头像、填写的昵称及更新时间 | 监护人同意本规则后陪同设置，只用于“我的”展示，不发送给大模型；可跳过或在“我的”恢复默认，不改变内容归属 |
| 年龄段和同意记录 | 年龄段，监护人同意的时间、规则版本和事项 | 适用本规则，证明已取得监护人同意 |
| 随心记 | 原话、理解、补充、标签、选择的图片，整理结果、卡片类型和关联、版本、收藏和提醒日期 | 记录和整理孩子的想法和学习内容。新卡保存后自动发给大模型服务方整理 |
| 拍照、传图和导入 | 拍摄或选择的图片、从微信聊天选择的文件、识别出的文字 | 识别题目和文字。导入的原文件用于识别和失败重试；清理规则见第七章 |
| 学习地图、练习、复习和错题本 | 作答和正误、查看提示和解析的情况、复习和复测安排、段位和经验、错题 | 判断对错，安排复习 |
| 问 AI、聊一聊和头脑风暴 | 提问、聊天里发的图片和文件（文件只留文件名、大小、类型和读出的文字）、对话记录、带入的卡片、头脑风暴报告 | 回答孩子的提问，做题时一步步引导。聊天里发的图片和文件交给 AI 处理 |
| 心情记录（监护人另行同意后） | 心情对话、心情卡、同意时间 | 回复、记录和安全初筛（见第十章） |
| 学习时长 | 每天在学习相关页面的时长（只保存按天汇总的结果） | 让孩子看到自己的学习节奏 |
| 反馈 | 反馈原因、备注、对应的题目和当时的作答 | 核对题目。我们的维护人员能看到这些内容 |
| 额度和功能使用记录 | 每日和每周用量、额度凭证、操作的类型和时间、是否显示过求助页面（均不含内容） | 执行每日和每周额度，防止滥用，维持功能运行 |
| 网络日志 | IP 地址、访问时间、请求的接口地址、响应状态及客户端随请求提供的标识等，具体字段取决于接入日志配置 | 保障网络安全，依法留存 |

3.2 **我们不收集与本服务无关的孩子个人信息**：不收集真实姓名、出生日期、身份证号、学校和班级、手机号、位置、通讯录，不自动读取微信昵称和头像，不进行人脸识别，不读取剪切板。小程序端未接入第三方 SDK。

3.3 **请监护人提醒孩子：不要在内容里写下自己或他人的姓名、住址、电话、学校等信息，不要向学习和 AI 功能上传有人脸、证件的照片；可选头像优先使用不含真实人脸的图片。**

3.4 小程序只在监护人同意本规则后、孩子主动使用相关功能时调用头像选择、昵称填写、相机和相册、微信聊天中的文件、剪切板（只写入）、拨打电话（只拨打 12356）和发送文件到聊天，详见《晓念隐私政策》第三章。

## 四、我们如何使用孩子的个人信息

4.1 我们只为第三章所列的目的使用孩子的个人信息，不超出监护人同意的目的和范围。确实需要超出的，会再次征得监护人同意。

4.2 **我们不会：**把孩子的个人信息用于广告或商业营销；出售孩子的个人信息；把孩子的内容展示给其他用户；设置用户之间的排名或排行榜；向孩子推送营销信息。第三方对内容的保存和使用规则见《晓念隐私政策》第四章、第五章。

4.3 **默认设置。**孩子的账号中，聊天时推荐相关的卡片、个性化学习推荐（地图上的“下一步”等）默认关闭，监护人可以根据需要在“我的”里开启。学习时长统计可以在“我的”里关闭。

4.4 卡片类型判断、答案是否等价、安全初筛等由程序自动完成，可能出错。卡片类型可以手动修改，答案判断可以点“这题有问题”请我们人工核对，详见《晓念隐私政策》第七章。

## 五、大模型处理

5.1 **发送什么。**整理、回答和判断时，我们只把完成当次功能所需的内容发给大模型服务方和判断服务方。**发送时不附带孩子的微信 OpenID、账号编号和 IP 地址等身份标识；但孩子写在内容里的个人信息，会随内容一起发送。**

5.2 **AI 生成的内容可能有误。**题目、讲解和回答都可能出错，不是专业意见。请监护人帮助孩子核实，必要时向老师求证。

## 六、委托处理、转移和披露

6.1 **委托处理。**云服务器服务商、大模型服务方和判断服务方协助处理孩子的个人信息，处理类别见《晓念隐私政策》第五章。**服务方与处理地域为【服务商及处理地域待配置】；保存期限和训练设置须按实际协议及账号设置核验，详见《晓念隐私政策》第四、五章。**我们对受托方的保护要求包括：

1. 按照法律、行政法规的规定和我们的要求处理孩子的个人信息；
2. 协助我们回应监护人提出的请求；
3. 采取措施保障信息安全，发生孩子个人信息泄露的，及时告知我们；
4. 委托关系解除时，及时删除孩子的个人信息；
5. 不得转委托。

6.2 **转移。**向第三方转移孩子的个人信息前，我们会自行或者委托第三方机构进行安全评估，并取得监护人的单独同意。

6.3 **披露。我们不披露孩子的个人信息，法律、行政法规规定应当披露或者根据与监护人的约定可以披露的除外。**

6.4 我们没有与其他个人信息处理者共同决定处理孩子个人信息的目的和方式的情形。

## 七、存储地点、保存期限和到期后的处理

7.1 **存储与处理地点。**孩子的应用数据、原图、备份及外部处理服务的实际地点为【服务商及处理地域待配置】。运营者须逐项核实并填写，详见《晓念隐私政策》第四、五、八章。

7.2 **保存期限。**可选头像和昵称保留至替换、恢复默认或注销；旧资料从在用数据中移除，备份依本章轮换。我们存储孩子的个人信息，不超过实现收集、使用目的所必需的期限：

- 孩子的内容和学习记录：保存到孩子或监护人删除、监护人撤回同意或者注销账号时。
- 心情内容：保存到删除，或者撤回心情记录的同意时。
- 导入的原文件：用于识别和失败重试，正常处理结束后清理；异常残留在服务启动时检查超过 1 小时的目录。1 小时是启动清理阈值，不是保证删除时限。
- 网络日志：应用服务器接入日志当前按天轮换、保留 14 份轮换日志，超出数量后清理。
- 备份副本：按计划每日备份，保留最新 14 份成功快照，超出数量的成功快照随轮换清理；失败目录需要人工处理，不保证在 14 天内清除。
- 其他信息的保存期限，见《晓念隐私政策》第八章。

7.3 **到期后的处理。**保存期限届满，或者删除、撤回同意、注销后，我们会删除孩子的个人信息，或者进行匿名化处理。**删除会立即从在用数据中生效；已经生成的备份副本不会立即清除，按最新 14 份成功快照轮换，失败目录人工处理；备份中断或失败时不能保证固定天数内清除，期间只用于灾难恢复。**

7.4 孩子年满 14 周岁后，可以在“我的”里更改年龄段，由孩子本人重新同意《晓念隐私政策》后，适用《晓念隐私政策》；在此之前，继续适用本规则。

7.5 **停止运营。**我们停止运营晓念的，会立即停止收集孩子的个人信息，至少提前 30 日在小程序内通知，留出导出数据的时间，并删除我们持有的孩子个人信息。

## 八、安全保障措施和安全事件处置

8.1 孩子的信息保存在应用数据存储系统中，并通过访问限制控制可查看的范围。

8.2 **最小授权。**我们对工作人员按最小授权原则严格设定访问权限，控制孩子个人信息的知悉范围。维护人员在管理后台看不到孩子写的资料原文、随心记、对话和心情内容。工作人员确需访问孩子个人信息的，须经儿童个人信息保护专人或者其授权的管理人员审批，记录访问情况，并采取技术措施，防止违法复制、下载孩子的个人信息。

8.3 其他安全措施见《晓念隐私政策》第九章。

8.4 **安全事件。**孩子的个人信息发生或者可能发生泄露、毁损、丢失的，我们会立即启动应急预案，采取补救措施；造成或者可能造成严重后果的，立即向有关主管部门报告，并通过小程序内通知、公告等方式告知受影响的孩子和监护人；难以逐一告知的，采取合理、有效的方式发布警示信息。

## 九、监护人和孩子的权利

9.1 监护人和孩子可以通过下列方式查阅、复制、更正、删除孩子的个人信息，撤回同意或者注销账号：

| 权利 | 怎么做 |
|---|---|
| 查阅 | 在孩子的晓念里查看各项内容和记录 |
| 复制、导出 | “我的 › 导出我的数据”，得到一个 JSON 文件（不含原图） |
| 更正、补充 | 卡片、标签等可以直接编辑；其他信息联系儿童个人信息保护专人 |
| 删除 | 逐项删除卡片、材料、对话、图片、头脑风暴等；“我的 › 心情记录”一键删除全部心情内容 |
| 撤回同意 | 撤回本规则的同意：在“我的 › 隐私政策”点“撤回授权并退出登录”，或联系儿童个人信息保护专人。**撤回后，我们停止处理并删除孩子的个人信息，相当于注销账号。**撤回心情记录的同意见第十章 |
| 注销账号 | “我的 › 注销账号，删除全部数据”。**注销后立即删除，无法恢复** |

9.2 **出现下列情形之一的，我们会及时删除孩子的个人信息：**

1. 违反法律、行政法规的规定或者双方的约定，收集、存储、使用、转移、披露孩子个人信息的；
2. 超出目的范围或者必要期限，收集、存储、使用、转移、披露孩子个人信息的；
3. 监护人撤回同意的；
4. 孩子或者监护人通过注销等方式终止使用晓念的。

9.3 孩子或者监护人发现我们收集、存储、使用、披露的孩子个人信息有错误的，可以要求我们更正，我们会及时更正。

9.4 **答复时限。**“我的”里的导出、删除、撤回和注销即时生效。通过联系方式提出的请求，我们在核实请求人与孩子的监护关系后 15 个工作日内答复；不能满足的，会说明理由。

## 十、心情记录

10.1 **孩子使用心情记录前，除了孩子本人在心情同意页上同意，还需要监护人另行单独同意。**

10.2 心情记录处理孩子写下的心情内容、心情对话和心情卡。这些内容会发给大模型服务方生成回复，发给判断服务方进行安全初筛、推荐相关卡片等。

10.3 **我们在心情同意页上告诉孩子：“AI 生成，不是心理咨询或医疗建议；有困扰，找专业人士帮忙。”**

10.4 **安全初筛和求助。**孩子输入的文字会经过自动初筛；可能存在自伤等安全风险时，晓念会停止生成回复，显示求助页面，提供心理援助热线 12356（全国统一）和紧急电话 110、120。**初筛可能误判或漏判。晓念不会通知监护人，也不会代为联系任何人或机构。请监护人关注孩子的情绪状况，发现孩子有危险时，请立即拨打 12356、110 或 120，或者寻求专业帮助。**

10.5 在“我的 › 心情记录”可以一键删除全部心情内容，带进过心情卡的对话和头脑风暴也会一起删除；撤回心情记录的同意，也会全部删除。

## 十一、防止过度依赖

11.1 按照《生成式人工智能服务管理暂行办法》的要求，我们采取措施防范未成年人用户过度依赖或者沉迷生成式人工智能服务：

- 晓念是学习工具，没有排行榜、广告、充值和营销推送；
- 每日和每周 AI 用量有上限；
- 孩子在问 AI 中问一道题时，晓念先给一步提示，引导孩子自己思考；
- 学习时长和连续学习天数只供孩子自己查看，不与他人比较；晓念不会因为连续天数中断而发送提醒。

11.2 我们建议监护人：陪伴孩子使用，合理安排使用时间；提醒孩子 AI 生成的内容可能有误，需要核实；不要让孩子把 AI 生成的内容当作作业或考试答案提交。
