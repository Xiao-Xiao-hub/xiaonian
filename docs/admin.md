# 管理台说明

`admin/`为原生HTML/CSS/JavaScript页面，由后端在`/admin/`同源提供，不需要独立前端构建。管理身份与学习用户身份分离。

## 本地预览与登录

```bash
bash scripts/dev-local.sh --no-watch --admin-preview
```

Windows：`.\scripts\dev-local.ps1 -NoWatch -AdminPreview`。访问`http://127.0.0.1:8788/admin/`，本次隔离实例的随机访问密钥位于合成数据目录的`admin-preview.key`；每次启动轮换，不写进日志或源码。该方式不读取`.env`，也不继承终端中的外部服务凭据，但会保留数据库中已有的接口配置。

管理台预览具备实际的配置和接口测试能力，不会自动模拟外部请求。只做离线预览时用`--data-dir`／`-DataDir`指定全新数据目录，并且不填写真实接口凭据；如果配置真实接口，测试和相关业务操作可能产生真实调用与费用。

配置环境通过`ADMIN_API_KEY`启用管理入口，生产还需精确的HTTPS `ADMIN_ORIGIN`。浏览器只在登录时提交访问密钥，换取HttpOnly、SameSite=Strict的短期Cookie；生产增加Secure。闲置15分钟或最长8小时失效，重启撤销全部管理员会话。

管理台不把密钥保存在URL、localStorage或sessionStorage。退出时请求服务端撤销；请求失败会明确提示，不能把本地清屏当成服务端已经注销。当前为单一管理员身份，`admin:shared`不能区分多名维护人员。

## 页面分工

| 页面 | 用途 |
| --- | --- |
| 工作台 | 用户、待处理反馈、失败任务、调用趋势与接口状态 |
| 反馈处理 | 查看用户主动反馈的题目、作答和备注，标记处理或重新打开 |
| 用户管理 | 查看账号概况，停用／恢复账号，设置个人预算 |
| 任务总览 | 查看队列、失败与未知任务，对符合条件的失败任务重试 |
| AI接口 | 配置接口地址、密钥、模型标识、识图能力、参数、顺序和场景路由 |
| 额度设置 | 设置日／周预算及计价表，查看部署默认值 |
| 题库 | 只读查看知识点、题目、答案和反馈；改题通过代码完成 |
| 材料与质量 | 查看资料、生成结果和反馈的聚合计数 |
| 用量与维护 | 查看匿名调用台账、token与估算消耗、存储情况 |
| 操作记录 | 按动作和时间查看维护审计 |
| 运行状态 | 查看进程、数据库、会话与外部服务配置状态 |

接口字段见 [API](api.md)。变更配置、停用账号或处理反馈会写审计。管理员不能执行主机命令；真实备份由维护者在主机上安排。

## 接口配置

第一次启动可从环境变量播种生成／识图接口，此后接口存储在数据库中，修改`.env`不会更新已存在的配置。新增接口后先测试对应能力，再按需要启用、排序和设置场景路由。测试会请求真实服务，可能产生费用。

模型标识是接入服务要求的技术参数，由维护者填写；产品功能说明统一称“大模型”。界面只回显已配置密钥的掩码，不应将完整密钥复制到文档、截图或日志。数据库及其备份包含接口配置，必须保密。

## 用量口径

用户预算按管理台价格表计算成功操作的日／周消耗；匿名总账记录外部网络尝试，重试逐次记录。删除内容不会返还已发生的额度消耗；注销账号清除个人记录，匿名总账保留。

供应商没有返回的token为未知，不能按完整零消耗理解。结果未知的调用可能已经计费，也不能自动重试。估算费用用于预算和运维，不是实际付款账单；价格、缓存和折扣需按真实服务协议核对。

当前用户数是保留账号数，不是历史累计注册数。当前队列覆盖全部未完成任务，成功率按统计期内已结束任务计算；空样本显示“—”。任务时间包括排队，不等于外部服务本身延迟。

## 数据和验证边界

管理接口以聚合计数和运行元数据为主；反馈处理会显示用户主动反馈时必要的题目、作答和备注。不要把统计权限扩大为任意读取用户卡片、笔记、对话或OpenID。单一管理员身份不代表已实现多角色授权。

“已配置”不代表外部服务实时可用，备份提示不代表已经执行备份。维护步骤见 [运行维护手册](runbook.md)。

```bash
node --test --test-concurrency=1 tests/admin*.test.mjs
node --check admin/app.js
(cd server && node --test --test-concurrency=1 --import tsx ../tests/admin*.test.ts)
```

页面行为测试不代替浏览器实际查看；修改管理台后检查窄屏、键盘操作、登录过期、加载失败和旧请求返回。
