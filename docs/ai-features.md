# AI 功能与维护入口

AI用于整理和生成建议，用户仍需核对原文、识别结果与答案。功能说明统一使用“大模型”和“判断服务”；接入的具体模型标识由维护者在配置与管理台填写。

| 功能 | 输入与输出 | 维护入口 |
| --- | --- | --- |
| 卡片整理 | 用户原话及补充 → 类型、结构化内容、关联建议 | `server/src/modules/cards/` |
| 聊一聊与讲一遍 | 当前消息、必要上文、主动带入的卡片 → 分段回复或反馈 | `server/src/modules/chat/` |
| 解题与批改 | 题目、图片、作答步骤 → 提示、讲解和核对结果 | `server/src/modules/chat/`、`server/src/shared/math.ts` |
| 资料学习 | 用户确认的资料版本 → 讲解、自测、引用和反馈 | `server/src/modules/study/` |
| 导入拆卡 | 用户选择并校对的原文分段 → 可确认的候选卡片 | `server/src/modules/imports/` |
| 头脑风暴 | 用户选中的卡片 → 共同点、分歧、方向与报告 | `server/src/modules/brainstorm/` |
| 分类、关联与风险初筛 | 当次功能必要的文本 → 类别、概率或是否关联 | `server/src/providers/`、`server/src/modules/safety/` |
| 图片识别 | 用户上传图片或文档扫描页 → 文字、题目和识别疑点 | `server/src/providers/`、`server/src/modules/imports/` |

## 调用过程

服务端先检查账号、同意与预算，再建立任务或开始流式请求。外部返回内容通过类型、字段、长度与引用范围校验后保存；复杂数学结果可再交给本地数学工具核对。页面通过任务状态或SSE更新，不将尚未完成的结果当成最终内容。

输出格式校验只能证明结构符合要求，不能证明内容事实正确。程序验算也有输入和能力范围，无法可靠判断时应保留“不确定”。高数地图预置题的作答使用本地程序规则；题库中已有的辅助起草来源记录与内容限制继续保留。

## 配置和更换服务

依 [后端运行](backend.md) 配置真实服务，再从管理台测试所需场景。生成、流式回答、识图和判断能力分别确认，单次连通不能替代所有功能验证。修改提示词或更换接口时，至少复查结构化输出、空内容、超时、不可用、离页后恢复、重复请求与失败不扣预算。

日／周预算根据配置价格表和记录的成功用量计算；匿名调用台账记录网络尝试。两者都不能代替服务方结算账单。真实请求可能产生费用，自动化回归测试使用服务替身。

## 内容边界

只向外部服务发送实现当前功能所需、当前用户主动提交或选中的内容。不把项目研究资料、审查日志、测试答案或开发文档混入产品资料。记录与生成结果分别保存，变更原文不能静默覆盖旧版本的依据。

公开副本法律文档是开发运行示例。接入真实服务前，维护者须按实际运营主体、联系方式、服务方与处理地域完善文档及平台隐私配置，并同步隐私版本；不能从源码可运行推断已经完成这些事项。
